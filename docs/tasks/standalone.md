# Task: make Agent IDE + Coordinator a standalone package (no Shepherdr install)

Today the layout is built on top of Shepherdr's mods (`chat`, `tasks`, `coordinator`, `spaces-chat`, `pane-chat`, `workspace-status-chat`, `new-menu-tasks`, `menu-tasks`, `task-*`, `artifacts`, `files`, `changes`, `git-graph`, `file-editor`, `tabs-tasks-git`, …) and on `herdr-task` + templates in `~/.config/herdr-core/templates`. Shepherdr is MIT (https://github.com/eliasstravik/shepherdr): vendoring it is allowed with the license text and attribution kept.

Plan: (1) compute the closure of mods the layout needs (grep `mod:` in the layout, then each mod's imports and `bin/`); (2) vendor them into this repo under `mods/` with `THIRD_PARTY.md` and the MIT notice; (3) rename and cut: drop the Shepherdr brand/service/web app/settings/bridge/usage/voice features not needed; keep task engine (`herdr-task`), coordinator, chat; (4) one installer (`install.sh`) that installs mods, templates (`assistant`, `worker`, `reviewer`) and skills, with no dependency on `~/.config/shepherdr`; (5) replace the Claude/Codex-only chat with `chat-acp` over time; (6) ship the i18n layer built in; (7) CI check: `herdr-app check` on every mod in a clean Herdr home. Done when a fresh machine with only Herdr installs it with one command and every Done-when item in RECIPE.md passes, with no `shepherdr` mods or folders present.
